# RapidResponseApp
Rapid Response is a menu-driven Java application designed to manage emergency ambulance calls efficiently. It allows users to register normal and critical emergency calls, prioritize patients based on urgency and distance, and dispatch ambulances accordingly.

Key Features:
Register normal and critical emergency calls.
Calculate ambulance charges based on distance and government schemes.
Estimate ambulance arrival time.
Prioritize and dispatch emergency calls.
Manage call records (add, display, search, delete and cancel).
Handle critical cases with ICU and optional ventilator charges.
Store and retrieve records using file handling.

Technologies & Concepts Used:
Java
Object-Oriented Programming (OOP)
Inheritance and Polymorphism
Encapsulation and Abstraction
Interfaces
Exception Handling
ArrayList and File Handling

Project Theme: Public Safety / Emergency Services
